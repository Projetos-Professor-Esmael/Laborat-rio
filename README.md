# NEXUS BIOHAZARD - WEB SCHEMA v7.7 ☣️

Sistema unificado e adaptado para **GitHub Pages** com suporte completo a banco de dados persistente simulado (`localStorage`) e upload dinâmico de imagens em formato Base64.

## 🌟 O que mudou nesta atualização?
- **Novos Atributos Estendidos:** Cada entidade do sistema passou a gerenciar informações adicionais e mais complexas.
  - **Biohackers:** Registro Técnico e Status.
  - **Experimentos:** Protocolo CEP e Autorização.
  - **Laboratórios:** Andar/Localização e Capacidade.
  - **Projetos:** Orçamento Estimado.
  - **Usuários:** Nível Hierárquico.
- **Atributo Foto Ativo:** Upload em tempo de execução codificado para Base64 armazenado de forma persistente. As fotos aparecem nas tabelas e no corpo do PDF gerado.
